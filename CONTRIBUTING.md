# Contributing

Thank you for helping improve ArnaVideo.

## Development

1. Fork and clone the repository.
2. Run `npm install`.
3. Copy `.env.example` to `.env` and add your own `GEMINI_API_KEY`.
4. Create a focused branch for your change.
5. Run `npm run lint`, `npm run typecheck`, and `npm run build` before opening a pull request.

## Pull requests

- Keep changes focused and explain the user-facing impact.
- Add or update documentation when behavior or configuration changes.
- Do not include generated media, local data, build artifacts, or credentials.
- Do not include third-party branding or assets unless their license permits redistribution.
